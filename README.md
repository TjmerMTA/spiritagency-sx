# sx.spiritagency.space

Сателлит агентства Spirit: витрина «Моделі агенції Spirit» — галерея, страницы моделей и блог из трёх статей.

- Сайт статический, лежит в `site/` — править можно прямо там.
- Выкладка: `./deploy.sh` заливает `site/` в ветку `gh-pages`, оттуда его отдаёт GitHub Pages.
- Домен: `site/CNAME`. В DNS нужна запись `CNAME sx → tjmermta.github.io`.
- Кнопки заявок ведут в Telegram агентства.

Откуда взят: восстановлен 03.10.2026 из темы WordPress Spirit Models — разметка, стили и тексты темы. Вместо фотографий — силуэты-заглушки из темы: исходные фото остались на выключенном хостинге.

Правки `<head>` и карты сайта для поиска (описания, canonical, превью `og.jpg`, хлебные крошки в разметке) делает
`_build/seo-fix.py <поддомен>` — после пересборки сайта прогнать заново. `site/og.jpg` — первый экран главной, 1200×630.
